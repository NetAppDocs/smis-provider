= Runtime library issues
:icons: font
:imagesdir: ./media/
:pp: {plus}{plus}

[.lead]
NetApp SMI-S Provider might encounter runtime library issues on Windows. Install the required Microsoft Visual C{pp} redistributable package to resolve them.

* *Issue*
+
You encounter runtime library issues.

* *Corrective action*
+
Install the Microsoft Visual C{pp} 2010 Redistributable Package (x86) from www.microsoft.com.
